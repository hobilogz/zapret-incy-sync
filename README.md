# Zapret & INCY VPN Sync Service

Легковесная фоновая служба для **Windows**, **macOS** и **Linux**, которая автоматически:
1. Выключает службу **zapret**, когда включается VPN в **INCY**.
2. Включает службу **zapret** обратно, когда VPN в **INCY** выключается.

## Преимущества
- **0.0% CPU**: служба работает по системным событиям изменения сети (`NetworkChange` в Windows, `launchd`/`sleep` в macOS, `systemd`/`sleep` в Linux) и практически не потребляет процессорное время.
- **Минимальное потребление памяти**: Windows-бинарник занимает ~9 КБ на диске и ~10-12 МБ в ОЗУ, на Linux и macOS bash-демоны потребляют менее 1 МБ.
- **Работает полностью в фоне**: стартует автоматически вместе с системой при включении компьютера без всплывающих окон.
- **Никаких сторонних зависимостей**: компилируется встроенным компилятором Windows (`csc.exe` из .NET Framework) / нативные скрипты под `launchd` (macOS) и `systemd` (Linux).

## 🪟 Инструкция для Windows

Все файлы уже подготовлены в корневой папке.

### 1. Установка службы:
1. Запустите файл `install.bat` от имени Администратора (правая кнопка мыши -> *Запуск от имени администратора*).
2. Скрипт зарегистрирует и запустит службу Windows `ZapretVpnSync`.
3. Готово! Теперь при включении VPN в INCY служба `zapret` будет мгновенно останавливаться, а при выключении VPN — подниматься.

### 2. Проверка работы / Интерактивный тест:
- Вы можете запустить `test_run.bat` (от Администратора). Откроется окно консоли, в котором в реальном времени будут видны логи при включении и выключении тумблера VPN в приложении INCY.
- История переключений записывается в файл `sync.log`.

### 3. Удаление службы:
- Запустите `uninstall.bat` от имени Администратора.

## 🐧 Инструкция для Linux

Файлы находятся в папке `linux/`. Поддерживаются все дистрибутивы с `systemd` (Ubuntu, Debian, Fedora, Arch, Linux Mint, Manjaro и др.).

### 1. Установка:
Откройте Терминал в папке `linux` и выполните:
```bash
sudo bash install.sh
```
Скрипт установит службу `zapret-vpn-sync.service` в `systemd`, включит автозагрузку и запустит её.

### 2. Просмотр логов / проверка статуса:
```bash
# Статус службы
systemctl status zapret-vpn-sync.service

# Логи в реальном времени
journalctl -u zapret-vpn-sync.service -f
```

### 3. Удаление:
```bash
sudo bash uninstall.sh
```

## 🍏 Инструкция для macOS

Файлы находятся в папке `macos/`.

### 1. Установка:
Откройте Терминал в папке `macos` и выполните:
```bash
sudo bash install.sh
```
Служба будет зарегистрирована в системном демоне `launchd` (`/Library/LaunchDaemons/com.zapret.vpn-sync.plist`) и сразу начнет работу в фоне.

### 2. Просмотр логов:
```bash
tail -f /var/log/zapret-vpn-sync.log
```

### 3. Удаление:
```bash
sudo bash uninstall.sh
```
